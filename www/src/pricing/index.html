FAQ

Fair questions, straight answers.

What is free, and for how long?

The complete mail client — sync, search, compose, filters, notifications, PWA, AI compose with your own key — is free under the AGPL-3.0, forever. Nothing is metered, and nothing will move behind a licence key later. Only the automation layer (REST API, MCP server, webhooks) is paid.

What happens when an annual licence expires?

You get a 14-day grace period with warnings. After that, only the automation layer stops — API, MCP and webhooks. The mail client itself keeps working forever, licensed or not. Your mail is never held hostage.

What does the perpetual licence cover?

One payment covers every mimux build released within one year of your purchase, and those builds run forever — automation layer included. Builds released after that need a new licence, but nothing ever forces you to upgrade.

How is the licence enforced? Does mimux phone home?

No. Licence keys are verified offline with an Ed25519 signature check built into the binary. There is no activation server, no machine fingerprint, and no phone-home — the app makes zero network calls to us, ever.

Can I try pro without a card?

Yes. A pro build runs the full automation layer for 14 days from first boot, no key and no card. When the trial ends the client keeps working — only the automation layer pauses until you add a key.

What does "per instance" mean?

One licence covers one running mimux server, no matter how many email accounts it connects to or how many agents talk to it. Run two servers, buy two licences.

Is there a refund policy?

14-day money-back guarantee on a first purchase, no questions asked — email mattmezza@gmail.com from the address you purchased with. EU and EEA consumers keep any statutory withdrawal rights that apply. Details in the terms.

Is the pro source code available?

Yes — the pro layer lives in the same public repository under the Elastic License 2.0, so you can read every line before buying. ELv2 allows almost everything except reselling mimux as a hosted service, circumventing licence keys, or removing notices.

Why is the automation layer paid at all?

Because email integration is never finished. Providers change auth, protocols drift, and someone has to keep the integration working for years. The licence funds that maintenance. The split is principled: a human driving mimux is free; a machine driving it is paid — and the line is published, so it can't quietly move.

Is there a GraphQL API?

Not yet — it's on the roadmap. When it ships it will be part of pro like every other machine interface, at the same price. Nothing about the licence changes.
